# Фронтенд (vanilla JS)

Статические файлы в этой папке: `index.html`, `styles.css`, `api.js` (все `fetch`), `main.js` (логика и DOM).

## Запуск

1. Поднимите бэкенд (например `http://localhost:8000`). В проекте включены **CORS** и раздача **MEDIA** в режиме `DEBUG`.
2. Откройте `index.html` через локальный сервер (из папки `frontend`), чтобы не упираться в ограничения `file://`:

```bash
cd frontend
python -m http.server 5173
```

3. В форме входа укажите **полный URL бэкенда** с протоколом, например `http://127.0.0.1:8000` (без `/api` в конце). Если там был сохранён неверный адрес, смените его и уйдите с поля (blur) — значение нормализуется. Иначе запросы уйдут на тот же порт, что и статика, и вы получите HTML 404.

Эндпоинты соответствуют роутеру Django: `/api/hostel/`, `/api/room/`, `/api/booking/`, `/api/auth/`, `/api/reviews/` (не обязательно совпадают с черновиком в READMY).
